Quitter le salariat

Ça fait trois ans que je n'ai pas travaillé dans un open space entourés des gens avec lesquels je collabore sur mes projets. J'étais embauché à distance en tant que Game Designer dans un studio allemand. Pour ne pas être seul, j'ai rejoins l'atelier One Shot, un espace partagé où une dizaine d'artistes se retrouvent pour partager et travailler sur leurs projets. J'aime travailler à l'atelier One Shot. C'est intéressant de voir ce que les autres font, ça permet de discuter de sujets un peu différent, de se soutenir, de s'entraider et de se donner de la force sur nos différents projets.


Un travail

J'ai besoin de faire un travail épanouissant. C'est-à-dire un travail qui m'intéresse, dans lequel je peux être compétent et où je suis convaincu par le but et la viabilité du projet.

Building a portfolio

I will explain on this page why I want to build a website for my portfolio.

If I want to be a UI/UX designer, I need to be able to prove that I am great at designing UI. Building a website is a great way of building UI.

I have several objectives in mind when building this website:
  • Focus on design, not tech. I am often using too much of my time learning the intricacies of complicated tech. This is great to continue to learn, but we can build great things with simple tech.
  • Learn how to build with references.
  • Learn the process to build websites.
